## Findings closed

Every finding below has a test. `tests/security/authorization-baseline.test.ts`
carries the R1-R9, S1, S2, S4-S8 finding-to-assertion map; the remaining
findings are covered in `tests/security/client-authorization.test.ts`,
`tests/security/signing.test.ts`, and `tests/security/transport-integrity.test.ts`.

### RBAC

- [x] R1 Role resolved from identity — `resolveRole`; baseline test plus client wiring
- [x] R2 Permission check reachable on real requests — provider resolved from the request URL
- [x] R3 Rate limits consume tokens — new `RateLimiter.tryConsume`
- [x] R4 Missing role no longer silently fails open — config validation plus `strict` mode
- [x] R5 `config.rbac` validated and read — `validateRbacConfig` in the resolver, wired in the client
- [x] R6 `allowedTools` / `deniedTools` enforced — `ToolPolicy`, client admission, and `ToolLoopAgent`
- [x] R7 Malformed policy rejected as configuration — constructor failure with a named field
- [x] R8 `maxBudgetPerSession` enforced or reported — budget view or a diagnostic
- [x] R9 Denial audits carry userId and role — attributed audit events
- [x] R10 Streaming denials surface as errors — `MiddlewareTransport.stream` throws `ProviderRequestError`
- [x] R11 Identity resolver exceptions handled — reported, never propagated

### Request signing

- [x] S1 Body bound into the signature — `v2` profile
- [x] S2 `verify()` recomputes the digest from received bytes
- [x] S3 Replay protection with timestamp window and nonce — `ReplayGuard`, `verifyFresh`
- [x] S4 Fresh signature per retry attempt — recursive `composeMiddlewares`
- [x] S5 `FormData` bodies no longer hash to a constant — no digest emitted
- [x] S6 No duplicate-case headers on the wire — normalized in `signingMiddleware`
- [x] S7 Key id authenticated by the signature — bound, and a mismatched header fails
- [x] S8 Per-sign nonce removes same-second collisions
- [x] S9 Correctly named digest header for non-SHA-256 algorithms
