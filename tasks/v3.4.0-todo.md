### RBAC

- [ ] R1 Role resolved from identity
- [ ] R2 Permission check reachable on real requests
- [ ] R3 Rate limits consume tokens
- [ ] R4 Missing role no longer silently fails open
- [ ] R5 `config.rbac` validated and read
- [ ] R6 `allowedTools` / `deniedTools` enforced
- [ ] R7 Malformed policy rejected as configuration
- [ ] R8 `maxBudgetPerSession` enforced or reported
- [ ] R9 Denial audits carry userId and role
- [ ] R10 Streaming denials surface as errors
- [ ] R11 Identity resolver exceptions handled

### Request signing

- [ ] S1 Body bound into the signature (`v2`)
- [ ] S2 `verify()` recomputes the digest from received bytes
- [ ] S3 Replay protection with timestamp window and nonce
- [ ] S4 Fresh signature per retry attempt
- [ ] S5 `FormData` bodies no longer hash to a constant
- [ ] S6 No duplicate-case headers on the wire
- [ ] S7 Key id authenticated by the signature
- [ ] S8 Per-sign nonce removes same-second collisions
- [ ] S9 Correctly named digest header for non-SHA-256 algorithms
