## Known pre-existing issues (not this release's scope)

Two of the three items flagged at the release commit were fixed in the
follow-up work; the third is still open.

- **Resolved — flaky tests.** Three tests failed under parallel load with
  timeouts: `production-audit` "10 concurrent complete() calls" (~26s),
  `v0.7.1-deep-audit` "API key not in error messages" (~3.5s) and
  `execution-optimization` "API keys not exposed in errors" (~10.4s). Root
  cause: all three built a bare `new HilbrasClient()` and so made **real network
  requests** to `test.com`. Fixed by injecting a stub transport (they now run in
  0.5s, 1.0s and 0.8s), not by raising timeouts. The two "API key" tests also
  used to pass vacuously when no error was thrown; they now assert the
  rejection.
- **Resolved — `tests/` was not typechecked.** `tsconfig.json` includes `src`
  only, so `npx tsc --noEmit` skipped the suite entirely. `tsconfig.tests.json`
  now covers `tests/`, wired as `npm run typecheck:tests` and enforced in the CI
  lint job. Compiling the suite for the first time surfaced **285 errors** across
  65 files — nearly all fixture drift: model fixtures missing the five newer
  `ModelCapabilities` booleans, `adapter: "openai"` widened to `string`, the
  Next.js handler result read as a `Response` when its type is a union, and
  several mocks built against APIs that had since changed. All fixed by
  correcting the fixtures. Verified: no `as any` / `@ts-ignore` /
  `@ts-expect-error` added, no test deleted, no test count changed. One test got
  genuinely faster for a real reason — `circuit-breaker-audit` had also been
  relying on real network failures (24s → 2.4s).
- **Resolved — short credentials leaked.** `redact()` matches
  `\bsk-[A-Za-z0-9\-_]{20,}`, so an `sk-` key with fewer than 20 characters after
  the prefix passed through untouched into error messages and logs. The SDK now
  registers the credentials it is configured with
  (`src/security/known-secrets.ts`) and scrubs them by exact value, which has no
  length floor and no false positives. Covered by
  `tests/security/known-secret-redaction.test.ts`.
- **Still open — `npx oxlint tests/` reports 63 warnings and 8 errors**
  (pre-existing; the lint gate covers `src/` only). The files added by this
  release are clean.
